开发清单。全部做完后再改写成正式的 README。每轮做完后更新：做完的删掉，新想法放进 TODO。

## 存在的问题

待验证（离屏测试测不了，要在真实桌面或游戏里试）：

**编辑器**

- [ ]  配置切换（标题栏右侧「配置：xxx ▾」）：列表、新建 / 复制当前、打开文件夹；重启后打开上次用的配置；切换前未保存的修改是否都写进了旧文件。
- [ ]  自绘取色器（`ColorPicker.qml`，替换了系统对话框）：位置、拖动取色、十六进制输入、最近颜色。
- [ ]  侧栏拖动的手感：拖起的行跟着鼠标，其他行滑开让位；拖到组那一行的中间放进组。折叠的组拖进去后保持折叠。松手后行停在落点；拖到列表上下边缘时自动滚动。
- [ ]  进度条「扣血残影」：下降时掉下去的那段先停留再缩回；连续下降、回升时的表现。
- [ ]  Buff 列表：新获得的排在后面、结束的移走后其余滑过去补位；锁定目标切换时列表跟着换；永久 Buff 不显示时间。
- [ ]  切换控件时，还停在输入框里的修改写回原来那个控件（离屏测试已通过）。
- [ ]  复制控件（侧栏右键「复制」或 Ctrl+D）：副本在原控件上方、偏移 16 px；组连同成员一起复制。
- [ ]  数字输入框（长度、宽度、旋转等）：输入后回车、切页签再切回来，值是否保留（离屏测试已通过）。

**触发器和数据**

- [ ]  触发器在真实游戏里的表现：Buff 匹配、技能释放事件、连携技冷却、动画是否流畅；「只在有触发器满足时显示」+ 播放一次 + 播完消失。
- [ ]  「战斗状态」读游戏的 `BattleManager.m_isSquadInFight`（Bridge v0.6.0 / ABI 1.3）：按波次刷怪时波次之间是否保持战斗中；大世界、剧情、菜单里是否误判。旧版 Bridge 仍用估算。
- [ ]  组的触发器：「只在有触发器满足时显示」时整组隐藏 / 显示；组效果在成员图标上的播放（含「播放一次」的时机）。
- [ ]  显示的「始终隐藏」：控件 / 整组在游戏里不显示，设置保留；选中时预览里淡显。
- [ ]  进度条：「自定范围」（例：三个方块分别 0–100、100–200、200–300 技力）；平滑过渡（默认 150 ms）是否跟手；分段、圆头、数值位置。
- [ ]  HP / 失衡改为显示真实数值后，各处的数字（文本、进度条和图标上的数值）是否都对。
- [ ]  Buff 的「层数」「剩余时间」比较、连携技的「剩余冷却」比较：在游戏里叠层、快结束时是否按时满足。
- [ ]  出现 / 消失动画（淡入淡出、滑动、弹出 / 缩回）：触发器反复切换时是否跟得上（中途切回从当前位置接着播）；组的动画作用到没设自己动画的成员。
- [ ]  满足时样式：变色、不透明度、发光（外发光 / 流光 / 像素边框）、循环动画（脉冲、呼吸、闪烁、抖动、旋转）在游戏里的观感；组的样式作用到成员；多个触发器同时满足时后面的覆盖前面的。

**游戏内显示**

- [ ]  无边框全屏和窗口模式下的位置、大小是否贴合；鼠标点击能否穿透到游戏；会不会抢游戏的焦点；切到别的窗口时是否被正常遮住；最小化 / 退出游戏时是否隐藏。
- [ ]  多显示器、显示缩放不是 100% 时的位置换算。
- [ ]  性能：控件多（几十个）、多个动画同时播放时，覆盖层的 CPU / GPU 占用，以及对游戏帧率的影响（每个控件是一个 Canvas，播放动画时每帧重画；流光 / 像素边框也是每帧重画，外发光的模糊最贵）。

已知问题：

- [ ]  插件启用前已经存在的 Buff 可能读不到（Bridge 的 Buff 表标记 `PARTIAL`），要等它刷新或重新获得才出现。
- [ ]  文本的控件框不跟内容变化：文字长于框时照常画出框外，但预览里选中 / 拖动只认框。
