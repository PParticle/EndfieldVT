## 存在的问题

待验证（离屏测试测不了，要在真实桌面上试）：

- [ ]  配置切换（标题栏右侧「配置：xxx ▾」）：列表、新建 / 复制当前、打开文件夹；重启后打开上次用的配置；切换前未保存的修改是否都写进了旧文件。
- [ ]  自绘取色器（`ColorPicker.qml`，替换了系统对话框）：位置、拖动取色、十六进制输入、最近颜色。
- [ ]  侧栏拖动的手感：拖起的行跟着鼠标，其他行滑开让位；拖到组那一行的中间放进组。折叠的组拖进去后保持折叠。松手后行停在落点（不再从顶端落下）；拖到列表上下边缘时自动滚动。
- [ ]  触发器在真实游戏里的表现（Buff 匹配、技能释放事件、连携技冷却、动画是否流畅）；「只在有触发器满足时显示」+ 播放一次 + 播完消失。
- [ ]  「战斗状态」改读游戏的 `BattleManager.m_isSquadInFight`（Bridge ABI 1.3）：按波次刷怪时波次之间是否保持战斗中；大世界、剧情、菜单里是否误判。旧版 Bridge 仍用估算。
- [ ]  复制控件（侧栏右键「复制」或 Ctrl+D）：副本在原控件上方、偏移 16 px；组连同成员一起复制。
- [ ]  数字输入框（长度、宽度、旋转等）：输入后回车、切页签再切回来，值是否保留（离屏测试已通过）。
- [ ]  进度条的平滑过渡（默认 150 ms）在游戏里是否跟手；分段、圆头、数值位置。
- [ ]  游戏内显示：无边框全屏和窗口模式下的位置、大小是否贴合；鼠标点击能否穿透到游戏；会不会抢游戏的焦点；切到别的窗口时是否被正常遮住；最小化 / 退出游戏时是否隐藏。
- [ ]  游戏内显示：多显示器、显示缩放不是 100% 时的位置换算。

已知问题：

- [ ]  游戏内显示不支持独占全屏：游戏若用独占全屏（Endfield 目前只有无边框全屏和窗口），任何外部窗口都会被盖住。
